# Skills

Agent skills for working with the reaxuse codebase. The layout mirrors
[VueUse's `skills/` directory](https://github.com/vueuse/vueuse/tree/main/skills):
a per-topic folder containing a `SKILL.md` plus one reference document per
function.

> [!NOTE]
> In VueUse these files are auto-generated by `packages/skills/build.ts` from
> package metadata. reaxuse currently maintains them by hand; once the
> metadata registry (see `scripts/update.ts` and `meta/functions.ts`) is
> complete, a `packages/skills` package will regenerate them.
