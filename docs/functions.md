# Functions

The function list is driven by `@reaxuse/metadata` (see `meta/functions.md`,
regenerated with `npm run update`).

## Ported

- [useToggle](/core/useToggle) — a Boolean toggler
- [useCounter](/core/useCounter) — basic counter with min/max bounds
- [useNow](/core/useNow) — reactive current timestamp

> 🚧 The remaining ~200 `@vueuse/core` functions are being AI-mapped (in progress).
> Out of scope for now: `router` / `rxjs` / `electron` / `nuxt` / `firebase` sub-packages.
